# Contributing to LocalStream

Thank you for your interest in contributing to LocalStream! We welcome developers to help us make the ultimate local video streaming platform.

## Ways to Contribute

- **Bug Reports**: If you find a bug, please open an issue and include clear steps to reproduce it.
- **Feature Requests**: Have an idea for a cool new feature? Open an issue and let's discuss it!
- **Code Contributions**: Submit a Pull Request (PR) to fix bugs or add features.

## Getting Started

1. Fork the repository on GitHub.
2. Clone your fork locally.
3. Create a new branch for your feature or bug fix: `git checkout -b my-new-feature`
4. Make your changes and commit them: `git commit -am 'Add some feature'`
5. Push to the branch: `git push origin my-new-feature`
6. Submit a Pull Request.

## Development Guidelines

- We use **Next.js**, **React**, and **Tailwind CSS**.
- Follow the existing code style and structure.
- Try to keep UI changes consistent with our "premium, dark-mode, glassmorphism" aesthetic.

Thank you for contributing!
